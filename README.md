# Mico Hospital — Healthcare Website

A static hospital website interface designed to present healthcare information, treatment categories, doctor profiles, and contact details in one place.

## Overview

Mico Hospital is a frontend practice project focusing on HTML page structure, custom CSS, content organization, and responsive-oriented layouts. It demonstrates how a healthcare organization's public-facing site might be presented.

## Features

- Contact information bar and site navigation
- Hospital introduction and healthcare service information
- Treatment or department highlights
- Doctor/team profile sections
- Patient-oriented informational content
- Contact form layout and footer

The contact form is a visual frontend element; no appointment-booking service or form-processing backend is provided.

## Tech Stack

- **HTML5** — content and page structure
- **CSS3** — layout and custom styling
- **Google Fonts** — typography
- **Font Awesome** — interface icons

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Mutheaswar/Mico-Hospital.git
   ```

2. Change into the directory:

   ```bash
   cd Mico-Hospital
   ```

3. Open `index.html` in a browser, or launch it through VS Code **Live Server**.

No installation or build step is required. Google Fonts and Font Awesome are loaded externally.

## Project Structure

```text
Mico-Hospital/
├── index.html
├── style.css
└── images/
```

## Current Scope

This is a **static frontend demonstration**, not a live hospital management system. It does not provide patient accounts, medical records, live appointments, or a connected database. Contact information and some site content are illustrative.
